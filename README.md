# 📊 Demographic Data Analyzer

Analyze demographic data using Python and Pandas by answering real-world statistical questions from the U.S. Census Adult dataset.

This project is part of the freeCodeCamp **Data Analysis with Python** certification.

## 🚀 Project Overview

The program loads census data and performs exploratory data analysis to answer questions related to income, education, occupation, race, age, and working hours.

## 📂 Dataset

- Adult Census Income Dataset
- Source: UCI Machine Learning Repository
- File used: `adult.data.csv`

## 📌 Questions Solved

- How many people belong to each race?
- What is the average age of men?
- What percentage of people have a Bachelor's degree?
- What percentage of advanced degree holders earn more than 50K?
- What percentage of people without advanced education earn more than 50K?
- What is the minimum number of work hours per week?
- Among people working minimum hours, what percentage earn more than 50K?
- Which country has the highest percentage of people earning >50K?
- What is the most common occupation among high earners in India?

## 🛠️ Technologies Used

- NumPy

## ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/yourusername/Demographic-Data-Analyzer.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python main.py
```
